## Selected engineering work

**stephan.zych.be, two runtimes from one content source.** One Markdown/JSON content source feeds two independent runtimes: an Eleventy/Lit/TypeScript web application and a Go SSH/TUI application. GitHub Actions validates the repository, builds both container images separately, publishes them to GHCR and deploys automatically to DigitalOcean. [github.com/monkeymonk/stephan.zych.be](https://github.com/monkeymonk/stephan.zych.be)

**Developer tooling around coding agents.** A Go tool renders one canonical source — agents, skills, MCP servers, rules and reusable instructions — into the configuration of several coding-agent CLIs, so the same engineering rules apply whichever tool is driving. Agent work runs on deterministic checks, reviewed diffs and Git worktrees, with sandboxing using Bubblewrap, Landlock and seccomp kept outside the agent's control. [stephan.zych.be/blog/ai-agent-sandboxing/](https://stephan.zych.be/blog/ai-agent-sandboxing/)
